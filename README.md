# NYC Station Accessibility by Borough

This project uses Python and SQL to compare the number and share of fully accessible MTA station complexes across New York City's five boroughs.

**Key finding:** Manhattan had the highest share of fully accessible station complexes (33.1%, or 40 of 121). Brooklyn had the most station complexes overall (156), with 22.4% fully accessible.

**Data source:** [MTA Subway Stations and Complexes](https://data.ny.gov/Transportation/MTA-Subway-Stations-and-Complexes/5f5g-n3cz/data)

**How to run:** Open `nyc_station_accessibility.ipynb` in Google Colab and run all cells.
